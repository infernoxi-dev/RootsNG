# Roots Restaurant & Café — Premium Responsive Recreation

A premium, responsive multi-page front-end concept inspired by RootsNG's public website and location page.

## Pages
- `index.html` — restaurant landing page
- `menu.html` — menu categories with image-led sections
- `location.html` — Aba, Enugu and Umuahia branch information with map links
- `about.html` — brand story
- `reservation.html` — responsive reservation request form

## Run it
Open `index.html` in your browser or use the VS Code Live Server extension.

## Important
- This is a front-end recreation, not the original Roots website and not affiliated with Roots.
- Menu names are illustrative category placeholders, not a verified current menu. Ask the restaurant about current dishes and prices.
- Reservation and newsletter forms are demo-only. They do not send data or confirm bookings.
- Real online orders, payment, reservation submission and live menu/pricing require the restaurant's authorized backend/API.
- Photos and fonts load from Unsplash and Google Fonts, so an internet connection is needed.
- Location details are based on publicly available Roots contact/location pages; confirm before visiting.


## Added pages and mobile image fix
This updated version includes separate Contact Us, Blog, FAQ, and Careers pages alongside About Us, Locations, Menu, Home, and Reservations. Navigation and footer links connect these pages. The Blog content and menu examples are sample content for the recreation, not verified live content from RootsNG. Contact, careers, newsletter, and reservation forms are front-end demos and do not transmit submissions to the restaurant. On touch devices, image hover zoom is disabled to avoid sticky hover behavior.
